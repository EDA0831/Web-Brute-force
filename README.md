Web Login Brute-force

로그인 폼을 대상으로 **사전공격 + 무차별 대입(brute force)**을 수행하는 파이썬 도구. 사전공격과 브루트포스를 여러 스레드로 동시에 실행하며, 하나가 비밀번호를 찾으면 나머지는 즉시 중단한다.

특징은 실패 응답을 먼저 학습해 성공을 자동으로 판정한다는 점이다. 사이트마다 로그인 성공/실패를 알리는 방식(상태 코드·리다이렉트·응답 본문)이 다른데, 이 도구는 틀린 비밀번호를 먼저 보내 "실패했을 때의 응답"을 기준으로 삼고, 그와 다른 응답이 오면 성공으로 판단한다. 따라서 대상별로 코드를 고칠 필요가 없다.

⚠️ 이 도구는 본인 소유이거나 명시적으로 허가받은 시스템에만 사용해야 합니다. 타인의 로그인 시스템을 무단으로 공격하는 행위는 정보통신망법 등 관련 법률 위반이며, 그로 인한 책임은 사용자 본인에게 있습니다. 이 프로젝트는 보안 학습 및 인가된 테스트 목적으로만 제공됩니다.

주요 기능
사전공격(Dictionary attack) — 워드리스트의 비밀번호를 한 줄씩 대입
무차별 대입(Brute force) — 지정 길이의 모든 문자 조합 시도 (기본 1~4자)
동시 실행 — ThreadPoolExecutor로 사전공격과 브루트포스를 병렬 수행
성공 판정 자동 학습 — 실패 응답을 수집해 대상 사이트에 맞는 기준을 스스로 세움
설정 분리 — 대상 URL·폼 필드·워드리스트를 코드 상단 CONFIG에서만 수정
왜 스레드인가 (ZIP 크래커와의 차이)

웹 로그인 공격은 I/O 바운드 작업이다. 요청을 보내고 서버 응답을 기다리는 시간이 대부분이며, 파이썬은 이 대기 시간 동안 GIL을 풀어주므로 스레드로도 여러 요청을 겹쳐 보낼 수 있다. 반면 ZIP 암호 크래킹은 CPU 바운드라 multiprocessing(프로세스)이 맞다. 작업 종류에 따라 스레드/프로세스를 골라 쓰는 것이 핵심이다.

요구 사항
pip install -r requirements.txt

설정

코드 상단의 CONFIG를 대상에 맞게 수정한다.

python
CONFIG = {
    "url": "http://example.com/login",  # 로그인 POST 주소
    "userid": "admin",                  # 크랙할 대상 아이디
    "id_field": "mid",                  # 폼에서 아이디를 담는 필드명
    "pw_field": "pwd",                  # 폼에서 비밀번호를 담는 필드명
    "extra_data": {                     # 그 외 함께 보내야 하는 고정 폼 필드
        "returnUrl": "",
        "refUrl": "",
        "siteId": "13",
    },
    "wordlist": "rockyou.txt",          # 사전 파일
}

필드명 확인 방법 — 브라우저 개발자도구 → Network 탭에서 로그인을 한 번 시도한 뒤, 요청의 Form Data를 보면 실제 필드명(id_field, pw_field)과 고정 필드를 알 수 있다.

워드리스트 준비

용량 및 라이선스 문제로 워드리스트는 저장소에 포함되어 있지 않습니다. rockyou.txt 등을 직접 받아 스크립트와 같은 폴더에 두세요.

사용법
bash
python Web_Bruteforce.py

실행하면 먼저 실패 응답을 수집해 판정 기준을 만든 뒤, 공격을 시작한다. 비밀번호를 찾으면 S_ID_PASSWORD.txt에 저장된다.

한계
브루트포스는 현실적으로 짧은 길이(기본 1~4자)만 유효하다. 온라인 공격은 요청마다 네트워크 왕복이 있어 긴 비밀번호는 사실상 불가능하며, 사전공격에 의존한다.
Rate limiting, 계정 잠금, CAPTCHA, 2단계 인증 등 방어가 있는 시스템에는 통하지 않는다 (그것이 정상이며, 올바른 방어의 예다).
